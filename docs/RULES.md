# Rules

Checked 2026-10-27 UTC. Rules are taken from help pages or the sample CSV. Inferences are marked. When two current pages conflict, the finding is a warning and both quotes are kept. This project is independent and is not affiliated with Shopify.

- Sample file linked from the using-csv page as help.shopify.com/csv/product_template.csv, which answers 403 to a client without a browser session and redirects to https://cdn.shopify.com/shopifycloud/product-knowledge/production/csv/product_template.csv

The current column table and the sample fetched on 2026-10-27 are both accepted. That sample's header says `Variant Barcodes` where the table says `Barcodes`, and `Option1 Linked To` where the table says `Option1 LinkedTo`. Older names stay accepted, including the 2022-01-26 headers `Standard Product Type` and `Custom Product Type`, and `Standardized Product Type` for the same product-category column. The product CSV page says older column names stay compatible.

Choice-field values are matched without case, because the sample uses `Active`, `TRUE`, `FALSE`, `DENY`, and `CONTINUE`, while the column table writes those words in lowercase. Spaces around a choice value, a fulfillment service, an image position, a Gift card or Requires shipping value, a money value, a quantity, a weight, or an inventory tracker are ignored, because no page speaks about them and a hand-edited file often has them.

A quote below is the supporting words from the cited page, kept under 25 words. It is lightly shortened: a full stop may be added, or a placeholder or a trailing clause cut, and a `/` in SCL041 separates the page's bullets. For a `sample` rule the quote describes what the sample shows and is not page text. `conflict` means two pages disagree, so the finding is a warning. `inference` means no page states the outcome. `sample` means the evidence is the sample CSV rather than a sentence on a help page.

## How a few rules are applied

- **Unknown headers (SCL004).** The using-csv page says "You can't add any other columns to your CSV file." The common-import-issues page says "This window displays when the headers of your CSV file are incorrect" and describes a mapping dialog. A blank header cell is the same warning. `Variant Barcodes` is the sample's name for the Barcodes column and is accepted.
- **Header case (SCL005).** Warning, basis conflict. The import-products page says "Column header names are case-sensitive" and describes a network error when titles do not match the template, with the example `Handle` rather than `handle`. The common-import-issues page says incorrect headers open a mapping dialog. The column table and the sample also disagree with each other (`Option1 LinkedTo` versus `Option1 Linked To`, `Barcodes` versus `Variant Barcodes`), so a case difference is a warning, not an error. The header is still bound to the documented column and produces no further finding. Older and alternate spellings listed in the code are exact matches and are not reported.
- **Repeated headers (SCL006).** Inference. Two headers that map to one column are a warning. The help pages do not say which value wins.
- **Trailing header space (SCL007).** Warning, and only when the last header cell has trailing whitespace: "Remember to check for extra white spaces at the end of the first line." Leading whitespace is trimmed and not reported. `--fix` removes trailing whitespace from every header name, not only that last cell. A leading space is left in place, unless the header is renamed to the documented spelling.
- **15 MB (SCL011).** Import products says "Your product CSV can't exceed 15 MB." The Open or edit a CSV file page says there is a file size limit of 15MB. Neither page says decimal or binary. Above 15,728,640 bytes (15 MiB) this is an error and the rest of the file is not read. From 15,000,001 through 15,728,640 bytes this is a warning and the file is still checked. For a regular file the count is the file size. For a pipe it is the number of bytes read when reading stopped, and the message says so.
- **Quotes (SCL012).** The message names the physical line where the quote opened (`Line 2: quote opened here is never closed`) and `row` is the CSV record number of that line. It does not repeat `Row N:`.
- **Extra cells (SCL013).** Inference. A warning only when a cell past the header is non-empty. A trailing empty cell is not flagged. The using-csv page is not cited for this.
- **Handle (SCL015).** A space is an error: "it can't contain any spaces." Another character, such as an underscore or a dot, is a warning: documented valid handles use letters, dashes, and numbers. Letters and numbers are Unicode letters and decimal digits. An empty handle on a single new product is allowed.
- **Repeated handles (SCL016).** Rows for one URL handle have to stay together. A later block with the same handle is an error. An empty handle with a Title starts another product. An empty handle and an empty Title continues the current product. The using-csv page does not say what a blank handle means. `--fix` keeps a blank handle under the row above it, so a titled blank row directly between two rows of one handle stays with the row above it, those rows are not brought together, and SCL016 stays in the report. A handle of only spaces is grouped like any other non-blank handle. Rows with the same handle are grouped even when a later Title differs, which can report SCL018 or SCL022. The Title cell is not changed. Two handle columns use the first one. A different case or a trailing space stays a different handle.
- **Product-level columns (SCL018).** Title, Description, Vendor, and Tags are supposed to be filled on the first row and skipped later. The same value, or a blank later cell, is fine. A different value is a warning.
- **Option names (SCL019, SCL020).** The sample CSV puts each option name on the first row of the product only. The same name repeated later is fine. A different name later, or a name that appears only on a later row, is a warning. The literal value `Default Title` is not required.
- **Price (SCL024, SCL025, SCL026).** A blank Price cell is a warning. The current table says "The default value is 0.00 if no value is entered." The older common-import-issues page says "Validation failed: price can't be blank." A currency symbol or letters are an error ("Only include the monetary value without a currency symbol."). `.99` is accepted. Surrounding whitespace is trimmed. A thousands comma, a minus sign, or another shape is a warning. Compare-at price has to be higher than price to display a sale. That is a warning, including when the two prices are equal, and including a compare-at price of 0.00. The sale-pricing page says a compare-at price of $0.00 is not the same as an empty compare-at price. `--fix` removes one `$`, `€`, `£`, `¥`, or an active ISO 4217 alphabetic code (list one as of 1 January 2026, including funds codes) when the rest is a plain number with at most two decimals. Only a space (U+0020) may separate the mark from the number. `10 OFF` and `SKU123` are left as written. A gram suffix on Weight value (grams) is removed on the same space rule, and only for `g`, `gram`, or `grams` after a whole number.
- **Choice lists (SCL027).** Closed lists introduced by "Valid values are:" stay errors. Surrounding spaces are ignored, so `TRUE ` and ` active` are accepted, and a value that is only spaces counts as blank. The status list is active, draft, and archived. The same pattern covers published, gift card, charge tax, requires shipping, inventory policy, weight unit, and packed unit. Inventory tracker says "Valid values include:" so an unlisted value such as `webgistix` is a warning. `Included / {market}` gives a default of true and does not list allowed words, so a value other than true or false is a warning.
- **Status (SCL044).** "If this column is present, then it needs a value." Later rows may leave it blank, which is what the sample does.
- **Gift card (SCL045).** `true` is a warning. A product CSV cannot create a gift card. `false` is fine. The checker cannot tell an update of an existing gift card from an attempt to create one.
- **Fulfillment (SCL041, SCL042).** Known values are `manual`, `shipwire`, `webgistix`, `amazon_marketplace_web`, and `gift_card`, compared without case. A custom value should be a lowercase handle of letters, numbers, and dashes. The using-csv page gives that shape as guidance for the service name ("Use only lowercase letters", "Replace spaces with a dash (-)", "Remove periods and other special characters") and does not say the importer rejects another value, so a different shape is a warning (SCL041). A custom value with a blank SKU is an error (SCL042). Surrounding spaces are ignored. A blank fulfillment cell is not flagged: the column table says the default is manual, and the common-import-issues page says fulfillment service can't be blank.
- **Inventory.** A non-numeric quantity is an error ("Inventory quantity is not a number"). A blank quantity with a tracker set is a warning. The current table says "The default value is 0 if no value is entered." The older page says "Inventory quantity can't be blank." A blank tracker and a blank quantity are left alone.
- **Weight (SCL038).** Warning. "You should specify only the numerical value, without the unit of measurement or decimals." A whole number of grams is quiet. A decimal or a unit is a warning. The 2026-02-01 sample contains decimals such as `226.796185`, and the page does not say the importer rejects them.
- **Images.** Product image URL and Variant image URL must be absolute `http:` or `https:` URLs with a host. Distinct URLs across both columns count toward 250, because a variant image has to come from the product's media list. A file name whose stem ends in `_thumb`, `_small`, or `_medium` is a warning. A `%` that is not a valid escape is left as written and does not abort the report. Alt text longer than 512 characters is an error. Alt text from 126 through 512 characters is a warning. Image position should be an integer of 1 or greater. The page says the images display in ascending order starting from 1 and does not say another value is rejected, so `0`, `1.0`, or text is a warning (SCL048). Surrounding spaces are ignored.
- **SEO.** Title longer than 70 characters, or description longer than 320, is an error. Length is Unicode code points. The column table also says the SEO title should be alphanumeric. The sample SEO titles contain spaces and punctuation, so this check does not enforce a character class.
- **Tags.** Split on commas, trim, and drop empties. More than 250 is an error. A symbol, or an accented Latin character, is a warning ("Avoid accented characters and symbols"). Letters and combining marks in other scripts, such as `帽子` or `टोपी`, are not treated as accented or as symbols. A combining mark after a Latin letter is an accent. Spaces and hyphens are allowed. The Open or edit a CSV file page says "Tags aren't case sensitive." This checker does not compare tag case.
- **Barcodes.** A cell may contain up to 20 barcodes, separated by `;`. `\;`, `\:`, and `\\` are escapes. A file that has both a Barcode column and a Barcodes column is an error. `Variant Barcodes` is the Barcodes column.
- **Packed product size (SCL043).** "Fill in all four packed product columns, or leave all four blank." "A file with values in only some of them results in an import error." "If a row sets Requires shipping to false, then these rules don't apply to that row." A file that merely has one to three of the headers, with every packed cell blank, is not flagged. The error is reported when a row whose Requires shipping is not false has a non-blank packed value and the four values are not all present.
- **Markets.** `Price / {name}` and `Compare-at price / {name}` (and the legacy `Compare At Price / {name}`) use the same money rule as Price. A market compare-at price with no fixed price for that market is an error. Lookup of the matching price column is by market name.
- **Option LinkedTo.** A non-empty value should look like `product.metafields.shopify.{taxonomy_attribute}`. Anything else is a warning. Both `Option1 LinkedTo` and `Option1 Linked To` are recognized.
- **Variant columns without options (SCL003, SCL047).** These warnings matter when you overwrite or update. A new simple product can omit URL handle, and a file of new products can omit the option columns. On overwrite, missing option columns delete existing variants. Do not treat these two warnings as import failures for a first upload.
- **One-line messages.** A control character, DEL, a C1 control, or U+2028 or U+2029 in a cell value or in a header name is shown as an escape such as `\n`, `\r`, or `\u0085` in the message and in the text report. The JSON `column` field keeps the header text as written.
- **Findings cap.** Each rule keeps its first 100 findings. The text report adds "and N more", and the JSON `truncated` field maps the rule id to the omitted count. `errorCount` and `warningCount` include the omitted findings.

Headers that are recognized and not value-checked: Tax code, Variant Tax Code, the unit-price measure columns, Google Shopping columns (`Google Shopping / ...`), product category, and any header that contains `product.metafields.`. `Collection` is recognized. Market columns match `Included / ...`, `Price / ...`, `Compare-at price / ...`, and `Compare At Price / ...`.

A header with a different case still binds to the documented column. It is reported once, as the SCL005 warning.

These findings stop the rest of the check: the file is over 15,728,640 bytes, the bytes are not UTF-8, the quotes do not parse, or there is no header row. A directory or an unreadable path is an I/O error from the CLI, not an encoding finding.

## Not checked

Limits and outcomes that are not a documented, file-only import rule are left out.

- A leading UTF-8 BOM is not documented. The parser strips U+FEFF and does not report it.
- Line endings. The create-CSV section says to save with LF. The official sample file is CRLF, and no import error on the help pages mentions CRLF. CRLF, LF, and bare CR are all accepted, and a CRLF inside quotes is kept.
- Curly quotes used as CSV delimiters. Straight `"` is the only quote character. Curly quotes inside a title are ordinary text; the sample title uses them.
- The SEO title "alphanumeric" character class. Length is checked. The class is not, because the sample contradicts a strict reading and the page does not define the class.
- Product category against the Standard Product Taxonomy, including "Not a valid product category". The taxonomy is not in this package, and the checker makes no network calls.
- Image size, 20 megapixels, 5000 × 5000, password protection, or whether a URL is publicly reachable. URLs are not downloaded.
- "Ignored line because handle already exists", and any other fact that depends on the store.
- Which existing fields a blank cell clears when "Overwrite products with matching handles" is selected.
- The daily limit of 10,000 new variants for a store that already has 500,000 variants and is not on Shopify Plus. That depends on the store.
- Theme, app, and sales-channel support for more than 100 variants. The import limit that is documented is 2,048, so 101 through 2,048 variants are allowed here.
- A required option value of exactly `Default Title`.
- A blank fulfillment service. The column table and the common-import-issues page disagree (default `manual` versus "can't be blank").
- A blank price when the Price column is omitted. The documented default is 0.00. A blank cell when the column is present is the SCL024 warning.
- Unit price total measure, unit price base measure, and their units. Those headers are in the sample CSV and are not described in the column table fetched on 2026-10-27 UTC. The headers are accepted. The values are not validated.
- Tax code and Variant Tax Code values.
- Google Shopping vocabularies (gender, age group, condition, and the rest).
- Metafield values by type. Option LinkedTo shape is the exception (SCL050).
- Whether a market name exists on the store. `Included / [Primary]` on the help page is a description of the primary market, not a literal header. Any `Included / ...` header is accepted.
- Barcode checksums and barcode type names. The 20-barcode limit and the Barcode-plus-Barcodes conflict are checked.
- Tag case. The Open or edit a CSV file page says tags are not case sensitive. This checker does not compare tag case.
- Multi-location inventory. A product CSV quantity is one location. A separate inventory CSV is a different file.
- Variant metafields. They are documented as unsupported. An unknown column is the SCL004 warning. The checker does not classify why the column was added.
- Spreadsheet damage other than split handle groups (SCL016) and duplicate option values (SCL022).
- Whether `Gift card` true is an update of a gift card that already exists. It is only a warning.
- Sales-channel columns other than Published on online store.
- Whether cost per item is higher or lower than price.
- Handle length, description length, vendor length, type length, and SKU character set. Those limits are not on the pages read on 2026-10-27 UTC.
- Uppercase handles. Letters are allowed. The pages do not require lowercase.
- A separate per-option value count, beyond 3 options and 2,048 variants.
- Gaps or duplicates in image position.
- An option name whose values are all empty.
- The relationship between cost and compare-at price.
